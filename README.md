# 🎬 AI-Based Movie Recommendation System

An AI-powered movie recommendation system that detects a user's
facial emotion and recommends movies based on their detected mood.

## 📌 About the Project

This project combines Artificial Intelligence with a web-based
movie recommendation system.

The system uses a camera to detect the user's face and analyze
their facial expression. Based on the detected emotion, the system
identifies the user's current mood and provides suitable movie
recommendations.

For example, if the system detects a happy expression, it can
recommend movies that match a happy or entertaining mood.

## ✨ Key Features

- 🤖 AI-based facial emotion detection
- 📷 Real-time face detection using a camera
- 😊 Emotion/mood recognition
- 🎬 Emotion-based movie recommendations
- 🖼️ Movie poster display
- 🔍 Movie browsing and exploration
- 🗄️ Database integration
- 🌐 User-friendly web interface
